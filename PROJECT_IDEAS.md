# 💡 Project Ideas

Kumpulan ide proyek untuk mempraktikkan konsep yang telah dipelajari.

## Beginner Projects (Sesi 1-4)

### 1. Personal Portfolio Website
**Konsep:** Halaman web statis tentang diri Anda

**Fitur:**
- Header dengan navigasi
- About section
- Skills section
- Projects showcase
- Contact form
- Footer

**Teknologi:** HTML, CSS, JavaScript

**Durasi:** 1-2 minggu

---

### 2. Calculator
**Konsep:** Kalkulator sederhana dengan UI yang menarik

**Fitur:**
- Input angka

## Project Progression Path

### Fase 1: Fondasi (Sesi 1-4)
```
Mulai dengan 1-2 project dari Beginner Projects
↓
Pahami HTML, CSS, JavaScript basics
↓
Buat portfolio atau calculator
```

### Fase 2: Vue.js (Sesi 5-9)
```
Lanjut dengan 2-3 project dari Intermediate Projects
↓
Pahami Vue directives, data binding, computed
↓
Buat Todo List atau Expense Tracker
```

### Fase 3: Advanced (Sesi 10-13)
```
Lanjut dengan 2-3 project dari Advanced Projects
↓
Pahami array methods, components, animations
↓
Buat E-commerce atau Drawing App
```

## Tips untuk Project

### 1. Start Small
- Mulai dengan fitur minimal
- Tambah fitur secara bertahap
- Jangan overengineer

### 2. Plan First
- Buat mockup/wireframe
- List semua fitur
- Plan folder structure
- Tentukan dependencies

### 3. Break Down Tasks
- Bagi project menjadi tasks kecil
- Selesaikan satu task sebelum lanjut
- Test setiap task

### 4. Use Version Control
- Gunakan Git
- Commit regularly
- Push ke GitHub

### 5. Test Thoroughly
- Test semua fitur
- Test edge cases
- Test di berbagai browser
- Test responsive design

### 6. Get Feedback
- Share dengan teman
- Minta feedback
- Improve berdasarkan feedback

### 7. Deploy
- Deploy ke production
- Share link
- Add ke portfolio

## Troubleshooting Common Issues

### Project tidak berjalan
- Check console untuk errors
- Verify file paths
- Check dependencies
- Restart server

### Performance lambat
- Check network requests
- Optimize images
- Minimize code
- Use caching

### Bugs yang sulit diperbaiki
- Use debugger
- Add console logs
- Isolate the problem
- Search online
- Ask for help
