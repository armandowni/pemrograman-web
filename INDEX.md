## 💻 Cara Membuka File Contoh

### Metode 1: Drag & Drop
1. Buka file `.html` dengan text editor
2. Drag file ke browser
3. Atau klik kanan → Open with → Browser

### Metode 2: Live Server (Recommended)
1. Install VS Code extension "Live Server"
2. Klik kanan pada file `.html`
3. Pilih "Open with Live Server"

### Metode 3: Command Line
```bash
# Jika punya Python
python -m http.server 8000

# Jika punya Node.js
npx http-server
```
