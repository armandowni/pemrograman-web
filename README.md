# Materi Belajar 📚 Web Programming Course - Complete Study Materials

Materi pembelajaran lengkap untuk kursus pemrograman web dari dasar hingga advanced dengan Vue.js.

## 🎯 Struktur Kursus

Kursus ini terdiri dari **13 sesi** yang dirancang untuk membawa Anda dari pemula hingga mahir dalam web programming.

### Sesi 1-4: Fondasi Web Development
- **Sesi 1:** Pengenalan Pemrograman Berbasis Web (HTML)
- **Sesi 2:** CSS & JavaScript
- **Sesi 3:** Implementasi HTML, CSS, JS (Todo List Project)
- **Sesi 4:** Lanjutan Implementasi (Notes App Project)

### Sesi 5-13: Vue.js Framework (Professional npm Project)
- **Sesi 5:** VueJS - Directives Dasar
- **Sesi 6:** Data Binding
- **Sesi 7:** Computed Properties & Methods
- **Sesi 8:** Watcher

## Cara Menggunakan Materi Ini

1. Buka folder sesuai sesi yang ingin dipelajari
2. Baca file `README.md` di setiap folder
3. Ikuti contoh kode di file `.html` atau `.js`
4. Praktikkan dengan membuat proyek sendiri

## Tips Belajar

- Jangan hanya membaca, tapi praktik langsung
- Modifikasi contoh kode sesuai kreativitas Anda
- Buat proyek kecil untuk setiap sesi
- Pahami konsep sebelum melanjutkan ke sesi berikutnya
